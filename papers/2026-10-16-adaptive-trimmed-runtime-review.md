# Runtime review of selected trimmed-face design

2026-10-16. Actual documents reviewed:
docs/adaptive-trimmed-construction-unit.md and
docs/adaptive-trimmed-numerics-unit.md. This does not self-approve the runtime
design. Read-only review; no product changes or execution campaign.

The source-qualified immutable constructions, original chart/physical identity
split, one directed-band CDT/flood, full face metric, original-root numerical
authority and SAME-L partition are constructive. The loop orientation and Euler
inventory are explicit enough to attack with the original-output reader.
Positive cycles count selected components, negative cycles count holes, and
interior sites require the new T=2N-B+2H-2C inventory rather than the old
boundary-only formula. No external containment hierarchy is needed after the
selected directed-constraint/flood mechanism and exact graph admission.

Two concrete integration findings were sent to both owners and parent:

1. Early outside classification prunes geometry. PatchSelection consequently
   contains a nonoverlapping NONOUTSIDE cover, not all prepared-root area. The
   numerical text's complete selected subtree/envelope statement must instead
   retain the runtime's complete branch partition including outside masks;
   geometry tests exact area coverage of each actual facet against the admitted
   selected leaves. Original planes can bypass leaf clipping after source
   envelope and selected-domain admission. Requiring all outside rows sampled
   or clipped would defeat that explicitly selected fast path.
2. A failed band facet can receive a strict interior anchor in local CDT. A
   failed packet facet currently cannot: packetbuilder takes leaf corners and
   common side events, while its geometric footprint is excluded from band CDT.
   Parent's every-failed-triangle anchor sentence and construction's band-only
   sentence therefore differ. Recommended constructive resolution is separate
   packet progress: split the owning leaf, rebuild packets/common rims, and
   require that the old failed packet facet is not emitted unchanged; use new
   strict interior anchors for band facets. Extending packets to arbitrary
   interior anchors is an alternative architectural addition, not a hidden
   existing capability. Parent selects the integrated rule before plan.

The numerical covariance/degree2 alternative is valid: for positive barycentric
weights, |E[U]E[V]-E[UV]| is at most range(U)range(V)/4. The coefficient hull and
covariance bounds can safely be minimized. Direct original N-WL avoids assuming
that a conservative eR+B-L failure witnesses geometric infeasibility. The exact
sum-of-norm threshold route must preserve signs before squaring, as selected.
Taylor interpolation on one C2 convex original support follows variance and
Cauchy; no C2 statement crosses C0 span cuts. Nonidentity domains still require
their real inverse map/displacement payload, never max boundary error.

Prepared analytic pi/2 panels are explicitly a deterministic preparation profile
choice, not required by the old <2pi guard or a global injectivity theorem.
Checked cuts remain literal stored dyadics; opposite periodic chart occurrences
retain separate coordinates and the same physical authority. This is a genuine
SourceCache extension, not a trace-purpose type cast.

Geometry owner accepted and corrected finding1: the admitted view is a disjoint
NONOUTSIDE partial cover, and direct original planes check envelope/domain
admission without leaf clipping. Scoped numerical DESIGN ACCEPT after that
actual correction; no remaining numerical blocker was identified in this review.

Reading adaptive_packets.cpp::Builder::zip sharpened finding2: an arbitrary
midpoint split can leave a skinny zipper triangle wholly inside one child and
emit it unchanged. A stronger packet-specific rule is to choose a canonical
root-relative dyadic point strictly inside the failed packet triangle, then
refine the SAME cache until that point is an active common grid corner. A
conforming packet mesh must use that corner, so the old triangle cannot remain.
The current depth64 profile can refuse if this is impossible within its cap.
This preserves the packet footprint and its existing side-event/zipper API.
Band triangles still require arbitrary-word exact anchors and local CDT. This
concrete alternative and monotone demotion were sent to parent for selection.

Parent selected the strict-interior active-grid target packet rule. Runtime
DESIGN now explicitly distinguishes it from band anchors, requires active target
incidence and caps/refuses unavailable paths. This resolves finding2 without
inventing a new packet triangulation API. Scoped construction/numerical DESIGN
ACCEPT after these resolutions, subject to matching construction text. The later plan
must bind actual header layouts, selection/constructed revisions and bounded
complete request horizons; this design review is not another certification
layer or an execution result.

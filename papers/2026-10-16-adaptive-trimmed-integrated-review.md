# Integrated trimmed-face design review

Read the construction, runtime and actual-facet numerical designs against the
existing packet zipper, source-cache descriptors, PatchSelection, shared-curve
caller, native source types and the checkpoint dependency plan. This review is
of the complete operation; it does not substitute for actual-source review.

The source contract is internally consistent: every physical edge/use remains
under the completed shared boundary authority, chart seam occurrences stay
distinct, and original spatial values are already mm. Reconstructed-selected is
an explicit reference domain. Authoritative straight-image identity requires
whole ORIGINAL pcurve/map/lift checks, not a boundary-error scalar or physical
curve line tag. Unknown curved authoritative interior maps remain unsupported
and explicitly required before promised broader import/assembly completion.

The directed-CDT/right-void flood is the selected connected-region mechanism.
Generalized Euler counts separate boundary and interior vertices and all
components. One fixed full face metric preserves exact source UV separately.
There is no need for a new hole-containment tree or a second triangulation to
choose the metric. Initial packet footprint fixes this generation's material
partition; common side events and local component rebuilds handle refinement.

Numerical acceptance keeps SAME actual affine L after every exact virtual clip.
The bilinear covariance identity is valid on arbitrary triangle pieces, with
the coordinate-range factor as an owned strengthening. Direct analytic Taylor
interpolation uses variance bounds on one C2 original rectangle; it must not
cross original C0 knots. Positive rational N-WL residuals retain original source
authority and exact positive denominator premises. Direct affine-plane testing
can skip clipping while retaining source/domain/envelope admission. Whole-facet
source truth in the external reader remains separate from backend equality.

Two actual integration defects were resolved before product edits. First,
selected public leaves cover NONOUTSIDE regions; requiring them to include
outside cells would undo early pruning. The owner retains the complete internal
classification partition, while actual facets check exact clipped area cover.
Second, one packet split can leave a skinny zipper triangle unchanged. Packet
failure now activates a capped prepared-root-relative dyadic point strictly
inside the old facet. The same cache and common packet schedule must consume
that point. Band failure instead installs its exact interior CDT anchor. Whole
unique target/path capacity is reserved before mutation, and capped failure is
unresolved. No termination theorem follows from this construction progress.

The minted source view and separate in-flight bank pin correctly distinguish
readable host results from CUDA resource lifetime. Original controls remain
opaque owner data; GPU child host placeholders must never be exposed as real
restricted nets. Two exact/compact point indexes must map to one point authority
in BOTH creation orders. Cover and point revisions invalidate actual bounds.

Integrated DESIGN accepted with these concrete resolutions. Literal API/schema
and direct RED order belong to the finite implementation plans and peer review.
This is not an implementation or performance acceptance. No product code or
geometry execution was performed as part of this review.

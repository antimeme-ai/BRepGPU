Two cross-document resolutions were sent to parent and peers:

1. PatchSelection contains only NONOUTSIDE leaves. The runtime retains the
   complete internal split/classification partition; geometry checks exact
   positive area coverage of each actual facet against the admitted disjoint
   partial cover. Requiring every outside branch to appear in PatchSelection
   would defeat early pruning. Numerical DESIGN wording is corrected. Direct
   original-plane bounds retain source-envelope and selected-domain admission,
   while deliberately skipping leaf clipping/area work.
2. Failed band facets can receive strict interior anchors in band CDT. Current
   packets consume corners and common side events, not arbitrary interior
   anchors. The integrated design must choose packet split/rebuild with an
   explicit unchanged-facet guard, or packet demotion followed by the band
   anchor path. The numerical failure key already names its generator; it
   must not invent unsupported packet anchors. Parent was asked to select this
   rule before the implementation plan.

Parent resolves item2 with a strict-interior prepared-root-relative dyadic
packet target: force the SAME cache until it is an ACTIVE common-schedule
corner, then rebuild packets and incident rims. Existing numerical allocation
may be reused; the incidence is new. A conforming triangulation containing that
interior vertex cannot contain the old triangle. Current axis-depth64 and target
path caps may return unresolved. An arbitrary one-axis split is insufficient
for skinny zipper triangles, so the explicit active target matters. No packet
demotion on bound failure is selected. Numerical DESIGN now matches this rule.

Scoped construction/runtime numerical/source/lifetime DESIGN ACCEPT with these
resolutions. This is not implementation acceptance or a performance claim.

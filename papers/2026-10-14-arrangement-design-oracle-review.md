# Bounded arrangement design: oracle tribunal

Reviewed `docs/ARRANGEMENT_DESIGN.md` against original body/coedge/control and
section/component/piece/event contracts plus the independent arrangement study.
Accepted, no blocking finding. No product code or execution occurred.

The admitted family provides a complete region oracle: full rational axial grid
cuts plus disjoint circle disks strictly inside individual cells. Several circles
may share a cell. Unsupported touching, clipping, nesting, duplicate geometry
and invalid sources fail the whole operation; they cannot silently disappear.
Exact bounded iterator admission prevents overlong/infinite inputs from becoming
an unbounded preparation path. Circle source identity must match the original
target snapshot/face on the selected operand; reversed operand order remains
supported without swapping away source meaning.

## Whole-circle edge and original occurrence provenance

One complete circle edge with one anchor is a sound graph representation. It
has two distinct opposed uses; its one-use disk loop and opposite cell-hole loop
both close at that anchor. The four source chart joins are retained event/map
provenance rather than four fabricated physical feature edges. The design's
counts correctly use+m vertices/edges, not+4m. The source study's alternative
four-quarter graph formula is conditional on that different representation
and is not the expected count for this design.

Admission explicitly requires a complete four-quarter rational source circle
with original named joins, bothUVs/spatial maps and component order. The oracle
must verify the complete source piece/event set and reader's whole parameter
coverage, not infer completeness because an anchor/circle label exists. Positive
separation excludes cross-circle/grid physical intersections, leaving original
source chart joins as curve representation metadata. Source-event and physical
graph-vertex counts are deliberately different.

## Complete regions, boundaries and readers

Independent truth enumerates every exact grid cell minus its listed disks plus
every disk, and matches a bijection to emitted region records. This proves
supported completeness without reconstructing product next links or relying
on Euler/count parity. Original face-boundary source coedge/edge IDs and increasing
exact source subranges are explicit. Canonical grid traversal can oppose the
original spatial edge parameter: qualification must derive that relation from
actual source coedge/curve maps, never infer it from numeric slots or assume
lo maps to canonical start.

All halfedges must have distinct opposite twins, inverse next/previous links,
matching endpoint continuity and exactly one owning region/loop. Compare complete
ordered cell/exterior sides and circle hole/disk words, allowing cyclic rotation
without reversal. Every undirected input interval is covered exactly once, with
twice-directed use coverage and no unreachable output records. Exact whole-map
UV/world polynomial identities and retained original source occurrences address
geometry/provenance separately from graph connectivity.

Exterior region0 is explicit, with a clockwise rectangle-hole boundary and no
bounded outer loop. Closed locate_uv output includes all incident cells plus
exterior on the original border; grid crossings retain all four cells and circle
boundaries both disk and parent. Witnesses are strict by exact separation, and
symbolic A+Bπ areas are normalizedUV with world scaling explicitly separate.
These mechanisms attack different faults; Euler remains only a consequence.

The root plan should exercise original top/bottom and grid-only vertical face
orientations, reversed boundary parameter direction, repeated/multi-hole cell
cases, selected source-side reversal and actual lookup/edge-reader outputs.
Source and cut permutations compare semantic signatures; result-local IDs and
section ordering need not become persistent cross-arrangement names. The design
already preserves this distinction.

No arbitrary clipped-circle solver, generic curved arrangement or Boolean is
required. Complete CPU construction/readers and actual consumer exports/costs
can establish this theme without reopening deferred integration tuning.

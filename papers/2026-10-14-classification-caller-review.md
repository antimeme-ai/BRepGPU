# Exact classification caller and cost-unit review

Source-reviewed examples/classify_geometry.py against the agreed product values,
complete-input ownership and qualification/cost design. No product import or
execution occurred locally. Accepted after integrating the findings below into
this caller only; root owns subsequent serial fleet execution.

**CC1 — bind qualification to actual submitted queries.** Point qualification
alone certifies the emitted world point, not correspondence to the submitted
query. A swapped symmetric query can preserve a label and bit-length digest.
Likewise contact qualification alone does not prove retained left/right input
references. Root identified the same finding independently. Fixed the outside-
timed qualification loop: result count must match count; every point retains the
exact submitted rational tuple and original snapshot identity; every contact
retains the actual submitted left/right FaceRef objects. Then the independent
geometry qualifier checks that output. No extra certificate or tests-for-tests.

**CC2 — show emitted contact geometry.** The graphic initially displayed actual
contact relation/dimension text but no contact locus. The semantics lane requested
actual miniature loci. Added polygon/segment/point drawings from each actual
result's world vertices in the common left-top XY plane. Empty results show an
empty marker. Parameterized source metadata remains text; no fabricated contact
points or raster generation are involved. Point-panel box/hole/cylinder outlines
now read original snapshot vertices/circle data and exact frame rather than
hardcoded display dimensions. Only final SVG coordinates round for display.

**CC3 — pin an imported source dependency.** Added python/brepgpu/__init__.py to
the retained source hash list because body factory records use its Patch/Lineage
classes. All product/body/intersection/oracle/test/caller sources are recorded
before and compared after the campaign. No new native library is used by this
pure exact CPU caller, so an irrelevant native binary pin is not invented.

The twelve cases are nine point cases (three shapes times three sizes) and three
contact sizes. Each constructs prepared bodies/queries once, then cold, one
excluded warmup and five repeated fresh owned result operations. Contacts include
coincident-opposed normals, area overlap, edge/point touch, coplanar next-float gap,
parallel subnormal offset, transverse interior crossing and boundary-confined
touch. Every point batch includes literals, subnormal radial excess and maximum
finite float plus deterministic rational clouds at larger sizes. Direct tests
separately cover translated-frame material traps and broader signed face roles.

Operation wall covers exact conversion, geometry and result publication. Consumer
wall reads every label/supporting face or contact metadata/world/bothUV value.
Complete wall includes both; every result's independent qualification and input
binding checks occur afterward, with their costs recorded. Preparation includes
body/FaceRef/query construction and remains explicit. "Cold" is the first call
within an already imported single process, not fresh-process runtime latency;
publication must preserve that scope. No CPU24/GPU comparison or residency claim.

Exact rational TSV exports preserve points, labels, original body/revision/face
identity, both UV maps and empty contact rows. Contact-source frames/names/normals
permit independent reconstruction of the canonical box recipes. The SVG reads
actual qualified results. Its coincident pixels explicitly do not erase exact
distinct values. Consumer checksum is a read marker, not the correctness oracle.

Static AST and diff checks passed after fixes. Fleet caller outputs, measured

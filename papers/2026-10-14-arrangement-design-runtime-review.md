# Arrangement design: arithmetic/runtime review

Read ARRANGEMENT_DESIGN against source SSI/body/classification and the bounded
arrangement study. Accept after the two explicit arithmetic/source clauses below;

**AR1 — prove the circle is circular in target UV.** Require equal nonzero
absolute world U/V spans for a circle-bearing target, and derive/check both UV
radii agree. A world circle on an anisotropic chart is a UV ellipse; using one
radius in Area.pi, disk separation and witnesses would be wrong. Existing owned
horizontal caps satisfy the condition, so this excludes no intended fixture.
Keep original face orientation separate from positive-UV region topology.

**AR2 — retain directed source curve parameters.** Root identified the cleaner
boundary provenance contract during review. Replace increasing source lo/hi with
oriented original-curve `(t0,t1)` for each canonical arrangement edge. Allow
t0>t1 and map arrangement t as `(1-t)*t0+t*t1`. The values address the original
spatial edge curve and its source coedge UV map; do not apply source coedge
orientation twice. Use.orientation separately reverses arrangement traversal.
Direct parameters make the actual source boundary readable without guessing
direction from table slots or a rounded coordinate match.

The one-edge/anchor circle contract retains all four original pieces and named
events without treating chart joins as new physical edges. Exact t traversal can
select the corresponding source piece/operand map; no sampling or float conversion
is required. Source operand identity, whole-component closure and four-piece/
event admission prevent a clipped curve from being promoted to an assumed disk.

Explicit count caps and limit+1 iterator admission bound records and reject
infinite cut/section iterables. Canonical grid generators establish shared
vertices/edges; circles remain source-namespaced. Pairwise strict disk separation
and strict cell containment exclude every unsupported contact before publication.
Arbitrary rational bit size remains a separate arithmetic cost and failure source.

All bounded regions, opposite uses and the exterior boundary are represented.
Next/previous/loop/region and source boundary parameters are actual reader outputs,
not a future sketch. Locate_uv returns every incident closed region at grid/
circle/original boundary points; this avoids a hidden arbitrary ownership choice.
Rational witnesses are guaranteed by the strict separation contract. Area's
rational-plus-pi values are exact UV measures, not physical areas or rounded
correctness certificates. Euler uses m+1 graph components and cannot replace
independent embedding/source/region truth.

Ownership is recursively immutable and complete-call failures leave input
snapshots/sections unchanged. No native/GPU lifetime, body mutation, history edit,
integration framework or shipping-language decision enters this beachhead.
Complete cost includes admission (including pairwise circle checks), construction,
publication and actual graph/map/location consumption; source SSI preparation and

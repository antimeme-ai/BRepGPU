# Pair discovery plan: independent oracle review

Reviewed `docs/PAIR_DISCOVERY_PLAN.md` against the accepted pair design and
independent study. **Accepted with no oracle blocker.** No implementation,
product import or native execution in this review.

The plan gives each whole invariant one owner and starts with an actual healthy
Engine/missing-operation fleet red before new product code. The oracle lane
owns direct tests and independent truth; the native lane owns actual resource/
failure admission; the scene lane owns body/input retention and consumer cleanup.
These seams need canonical field/method handoff before dependent tests, without
parallel POD definitions or independent lifetime frameworks.

The direct campaign covers the distinct mathematical/index fault classes:

- Exact original positive-weight control extrema, actual local root endpoints
  and actual downloaded world-box enclosure, rather than ideal boxes or CPU
  parity. Different-frame coincidence and local-equal/world-separated cases
  attack accidental local-coordinate comparisons.
- All actual-box closed overlap bits, including degenerate face/edge/corner
  contact, finite extrema, signed zero and subnormals. Analytic witnesses and
  intentional concentric/hole false positives distinguish carrier culling from
  an unimplemented surface/trim classification.
- Unaligned page starts, asymmetric collections, exact tail zeros, complete
  concatenation, empty/full/suffix/terminal metadata and progress independent
  of survivors. The 65,536² last-pair/terminal case directly checks total 2^32
  with small page storage.
- Namespaced face selection, exact retained source/scene identity after public
  close, and explicit boundary failures. Existing guarded callback scenarios
  attack upload/download/restore/publication/fatal failures without requiring
  unsafe physical-device fault injection.

Closed-contact, page-offset, tail-padding and world-transform production mutants
are a proportional set: each changes one claim tested by an independent direct
mechanism. Baseline must pass first. Isolated mutant source/logs do not become
product or another receipt layer. No fabricated functional red is needed for
unchanged legacy numerical operations; regression/compatibility runs address the
actual shared-registry/plugin change.

The initial caller scenes fit one capped page (about 28² and 936² pairs for the
stated repeated shape recipe), while direct tests separately establish arbitrary
page continuation. The measured matrix uses matched source conditions, excluded
warmup, five actual repeated calls and named host/device/setup/decoding costs.
It explicitly avoids sums of independent medians as wall latency and keeps exact
qualification/export outside reused timing. A fast bitset alone is not a CAD or
SSI speedup. Keeping this bounded all-pairs operation and moving next to an
intersection consumer is preferable to extending its pruning framework now.

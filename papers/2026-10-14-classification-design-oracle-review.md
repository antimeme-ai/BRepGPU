# Material and finite-face classifier design: oracle tribunal

Reviewed `docs/CLASSIFICATION_DESIGN.md` against the owned original body/frame/
chart records, existing exact SSI scope and independent classification study.
Accepted, no blocking finding. No implementation or product execution occurred.

The point contract classifies the exact submitted int/Fraction/finite-float
value, with exact world-frame subtraction/division. Closed feasibility precedes
boundary equality collection, avoiding false cap/hole/extended-carrier boundary
labels. Sorted supporting faces include every true original incident face;
periodic seam charts do not invent material faces. Unsupported/nonfinite/type
failures remain distinct from legitimate exterior results, and batches publish
no partial answer on failure.

The finite-face contract is bounded to original axis-aligned affine rectangles.
Its closed locus preserves point and segment contacts. Carrier coplanarity and
full finite-domain equality are separate; normal agreement does not erase a
coincident domain or make a transverse finite-edge touch into crossing. The
relative-interior midpoint rule is sufficient for this convex segment family.
Fixed-axis interval intersection can yield at most dimension2, and area output
is exactly four corners in left-chart positive parameter orientation. Disk,
hole-cap and wall contact remains explicitly unsupported rather than returning
an empty result by guessing curved trim overlap.

Independent qualification will use original rational world corners, support
planes and inward edge halfplanes. Enumerating rank3 plane intersections gives
the COMPLETE extreme corner set of a bounded rectangle intersection; affine
rank supplies dimension and original source maps supply both UVs. This differs
from the product's world interval algorithm. Compare complete corner sets first,
then declared ordering, and exact original control correspondence. A midpoint
or finite grid alone is not a completeness oracle for the polygon.

The model for material membership can remain in world coordinates and clear
original scalar denominators rather than repeat product local normalization.
Literal center/cap/corner/hole/rim/seam fixtures and all incident face IDs add
direct source truth. Required numeric witnesses include
`(1/4,2^-1074,0)` and origin offsets2^-1074: a rounded intermediate can change
radial or plane classification even when the input frame is admitted. Exact
Fraction(3/20),Fraction(1/5) are a circle boundary; their rounded binary64 values
are classified independently as actually submitted. DBL_MAX/normal/subnormal
and large rational values exercise the stated input contract without selecting
a native or GPU arithmetic architecture.

Retained FaceRefs/snapshots keep body/revision/face/chart identity; swapped source
order swaps UV roles while preserving the exact world locus. Geometrically equal
distinct bodies remain distinct sources. No numerical API process handles are
introduced, and existing GPU/native code does not acquire implicit new routing.

The design correctly limits performance claims to exact CPU construction and
complete caller costs, with conversion/publication and independent qualification
separately named. Python's shipping role and future filters/native placement
remain deferred until the breadth sweep. The subsequent plan sets concrete red,
direct fixture/mutation/caller and batch-size scopes before implementation.

zero. Exact degree(2,1) controls satisfy numerator<=W with no coefficient-rounding
allowance and keep existing Frame/descriptor semantics. Explicit circle_y avoids
silently changing old XY circle records. Native angular derivatives are rational
quarter derivatives; world position and unit-normal error are graded separately.

sqrt-halfspace comparison avoids a floating material-classification shortcut.

ABI5 degree-two opposed mates, including same-face neighbors. Four charts do not
claim four physical faces. Complete vertex links, source-derived whole geometry,
exact UV maps and precise six-kind origins cover faults Euler/count checks miss.
The operation retains the original factory profile; old public type guards and
canonical tags remain unchanged. A separate request/sample factory can reuse the
existing genuinely generic metadata/row/cleanup helpers without API widening.

Admission bounds total queries before allocation; native/host failure publishes
no partial batch, closes owned children and preserves borrowed Engine and valid
result for retry. Optional unprofiled kernel time remains NaN. Source publication
and consumer failure have distinct ownership boundaries. No native build is needed.

360 degrees with retained original handles and actual parameter/point probes.

research. Compare manifold/bounds/volume/boundary witnesses without foreign
representation/history equality. Existing required external alpha suites remain
an explicit gap. Complete prepared-profile and points walls include the actual
history/material/native/CSR reads and cleanup, with qualification/exports/reference
outside and nested phases nonadditive. Grid9 and distinct3/6/16-edge meridians
are meaningful bounded costs; no GPU construction or full-caller win is assumed.

# Convex extrusion construction: independent source review

Reviewed the complete `python/brepgpu/extrusion.py` source against the accepted
design/plan while developing a separate original-profile qualification model.
**Accepted; no blocking finding.** This report concerns source inspection; fleet
qualification evidence is recorded separately.

Admission preserves exact original numeric values and bounds outer/coordinate
iterables before materialization. Every edge tests every nonincident vertex;
positive adjacent turns cannot substitute for that global support requirement.
Exact lattice limits and positive height keep all emitted bilinear controls
representable without fitting, clipping or normalization. The factory-only
profile/result types keep previous canonical/Boolean contracts scoped.

The actual assembly builds two translated cap graphs and every complete side
from source endpoint identities. Reversed lower cap record order still maps to
the original source edge/coedge ID, rather than the reversed output slot.
Side intrinsic UVs follow source edge directions; occurrence signs supply the
single traversal reversal. The published readers preserve Fraction requests,
actual all-support material classification and original per-Patch frames.

The validator binds entire curve/incident-surface identities, complete ownership,
opposed physical uses, connected shell and cyclic vertex links. The independent
qualifier additionally reconstructs the exact literal graph and affine controls
directly from profile vertices; it does not call this validator. History origin
checks bind actual target roles to original typed parents and all affine maps,
not merely mutually consistent forward/reverse tables. Centered cap copies are
modified, and side births have explicit source-edge or source-vertex parents.

The private final validation runs before returning an immutable result; failure
can consume a namespace but cannot mutate existing profile/result tuples. The
constructor has no native child handles. The caller's complete wall is still
needed for result publication and useful consumption; nested phase timings are
not a replacement. No source correction requested.

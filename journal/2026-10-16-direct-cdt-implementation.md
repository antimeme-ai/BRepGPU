`feat/direct-cdt` on the reviewed study branch, preserving the staged history.

separate conceptual lanes. Each must produce a concrete reviewed plan before
implementation. The root lane owns the C ABI, lossless metric packing, build
integration and actual mesher connection.

A fresh isolated fleet checkout holds this work. The long-running historical
watch worker and its pinned source/binary checkout remain untouched. No new
library dependency is selected. General workload families and retained exact
watch inputs were selected before performance tuning.

The boundary plan specifies sequential exact input validation and direct
construction, cumulative work budgets, measured peak memory, strict source-ID
types, separate metric weights and fail-closed output publication. Implementation
and numerical/algorithm claims remain pending their actual fleet checks.

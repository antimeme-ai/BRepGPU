The operator authorized the proposed next tranche. Start with its concrete
first implementation: mesh the actual CutResult before extending another feature
or starting integration tuning. Read current doctrine, roadmap, exact Boolean and
canonical mesh contracts/code, existing mesh literature/oracles and caller scopes.

caller/measurement. Product geometry and tests execute only on the fleet.

original history, result source IDs and per-chart frames. Cutter wall keeps
raw V[1/4,3/4] and twice-scale frame; no canonical-plate reconstruction/type-guard
widening. Reuse only shared immutable mesh value records and compatible helpers.
Independently qualify exact/rounded whole-domain coverage, original source maps,
shared boundary/manifold and error budget. CPU-only, no new dependencies/builds.

# OCCT reference visualization

Root accepted docs/occt-watch-reference-unit.md before product code. The operation
uses the already adopted pinned OCCT reference stack, the unchanged original
STEP/BinTools exporter and existing raw native CPU display. It changes no owned
mesher, source geometry, NVIDIA operation or shared build target.

The new direct fixture first failed because the new caller did not exist. That
genuine missing-operation RED is retained under context/occt-reference/.
The standalone native/occt_reference target then built strict Clang18 Release
with -Werror against the existing reference OCCT installation. Source maps use
NbShapes-serialized_storage_index+1 and validate the actual root face membership
and orientation; traversal ordinals are not original FaceIDs.

The SAME real authored box/cylinder STEP operation passed: two definitions,
nine original faces, three placements including a proper rotation, original
box/cylinder point and normal equations, positive actual triangles, original
instance matrices and two actual native display PNG frames. Existing-output
refusal and missing-source failure passed with no complete image claim for the
failed operation. This is a finite reference-boundary check, not a whole-surface
deflection certificate. No whole-watch reference operation has run at this
checkpoint; root coordinates that attempt after independent source review.

The numerical peer accepted both the written plan and actual source: the same
ShapeSet retains source shape identity, reverse storage references bind exact
root members, orientations and triangulation locations are applied once, and
normal pseudovector handling agrees with triangle roles. The full original
inventory/PASS gate precedes display. The parent was notified that strict build,
the finite authored operation and actual-source review are closed; the complete
watch attempt awaits its resource go-ahead.

OCCT BRepMesh_IncrementalMesh receives absolute requested deflection .005mm,
angular deflection .5rad and serial meshing. OCCT computes normals from source
UV estimates with its triangulation fallback; face reversal and triangulation
location are applied by the exporter. Every original source face must have
finite nonempty triangulation; no definition or face is skipped on failure.
Images and metadata say OCCT REFERENCE. The authored palette/layout/cameras are
owned presentation and currently unmatched; they are not owned meshing results,
NVIDIA output or final5micrometre CPU/P100 comparison evidence.

The emitted views.bgview, source digest, BOM and explosion rows also naturally
match the existing NVIDIA caller's legacy matched-input schema. That observation
does not invoke NVIDIA or relabel the OCCT mesh; it only makes the same authored
camera/placement inputs available for a later separately selected reference run.

The first complete original-watch attempt exposed a source-query prerequisite:
all definitions were serialized without stored triangulations and some curved
faces lacked CurveOnSurface representations. The smallest retained four-face
original definition triangulated only three faces (status Failure); its missing
cylinder face had four missing pcurves. The authored box/cylinder fixture had
those representations, so its earlier success did not establish this import
precondition.

Root and the numerical peer approved the existing deep-copy RAW source UV
preparation, with `prepare_query=false`. It preserves the original admitted
face map and binds each prepared face through `prepared.mapped(original_face)`;
source bytes and original 3D geometry remain unchanged under the helper's
physical guards. This selected RAW stage includes guarded projection, seam
translations and conic chart guide preparation; finite correspondence probes
are reported, not presented as a whole-surface certificate. Optional query
columns, domain edits, joints and pole connectors remain disabled. The SAME
four-face original operation then produced four triangulated faces, flags zero.
The SAME two-definition/nine-face/three-placement fixture passed again. The
numerical peer read the actual adapter and standalone linkage and accepted the
original-ID mapping, copied-handle lifetime and RAW-only invocation.

The authorized fresh v2 whole-watch operation attempted all 107 definitions and
9,162 original faces with serial OCCT meshing and CPU12 even-core affinity for
the later display. It ended after 15.22 seconds (14.39 user, .82 system;
198,396 KiB maximum RSS). 101 definitions emitted complete meshes containing
239,224 triangles. Six definitions refused: four contained collapsed actual
OCCT triangles after all their faces received triangulations; two retained
missing face triangulations despite present pcurves (one cone face and six
spline faces). The four former status masks were 65 (OpenWire|Outdated); the
latter were 4 (Failure), according to the pinned IMeshData_Status enum. No face
or triangle was omitted to force completion. The complete-inventory gate
prevented display and no complete watch images were produced. This establishes
neither a successful full OCCT reference nor a defect in the immutable original
CAD by itself. Tables, original outputs, producer hash and process statistics
remain ignored under context/occt-reference/watch-actual-v2.

The SVG producer now explicitly credits OCCT reference meshing and BRepGPU
display/palette/labels. Its timing caption separates fresh STEP export, all-part
UV-preparation-plus-serial-meshing wall time and the shared two-view CPU display
wall time. Those image timings will exist only for a complete operation.

A diagnostics-only strict rebuild then replayed just the six retained failed
jobs, without fresh import or parameter changes. Each of the four collapsed
triangles has two distinct UV seam/pole nodes whose exported binary64 XYZ are
bit-identical at a sphere pole or cone apex; angular coordinates differ by a
whole turn. The physical collapse is genuine, not a long-double cross-product
underflow or assembly transform error. The missing inventory is one cone face
and six BSpline faces, all with present pcurves. Exact private original IDs,
actual corner words and UVs remain only in the ignored diagnostic log. No
triangle filtering, optional query-topology preparation or geometry repair has
been selected. The full-image operation therefore remains incomplete.

Root and the numerical peer then accepted the literal existing source-linked

The strict standalone build passed, then the SAME six retained failed jobs
were replayed once. All six still failed the unchanged gates. The four pole/apex
definitions now have OCCT flags zero, but still contain the actual zero-area

correspondence residual was 5.3448215025199131e-5mm. These reported probes do not
certify the output, and their small values did not make meshing complete.

The six-definition prerequisite did not pass, so no further authored test or
full v3 attempt was launched. Root explicitly stopped this external-reference

# Whole-mesher shared-feature and face-construction plan

Wrote `docs/native-mesher-topology-plan.md` as the topology owner's proposed
implementation unit after accepted whole design `f7aedef`. No product code or
tests were written or run. Read the actual current source edge/coedge records,
endpoint use, exact domain validator, immutable initial CDT/predicate headers,
and runtime/algorithm resolutions to ground the native seams.

The plan retains the existing edge parameter endpoint→vertex mapping without
reinverting `curve_same_sense`, owns original-parameter interval forests/common
face joints and all incident boundary generations, and bypasses the known
quadratic hole-containment wrapper through a new indexed exact domain admission
plus typed initial CDT. Appended arbitrary dyadic sites belong to mutable face
predicates, not the immutable initial predicate table.

Specified metric/circumcenter/Phi arithmetic, sticky heuristic ancestry,
terminal-priority LEPP transactions and deterministic queue frontiers. Actual
physical facets have an exact plane/convex-intersection classifier with allowed
contact derived solely from source/mesh incidence. A definition-owned BVH and
frozen contact epochs prevent completion-driven refinement or independently
approved conflicting flips. Singular cell coverage/refinement is an explicit
geometry-owner interface; there is no guessed ordinary-UV adapter.

Recorded authored failing semantic cases and independent performance families
before watch tuning, with complete costs/work/adverse results and no numeric
SLA. Sent typed value and ownership seams to geometry/runtime owners; root will
integrate and review the whole plan before implementation. No dependency
adoption, extra oracle tier or benchmark campaign.

Independent runtime review found an incomplete source-boundary request horizon:
ordered merging alone could cancel a slow face before its request arrived.
Resolved with a complete per-definition epoch: every current active face reaches
its canonical first request or bound-settled horizon before any split is applied.
Unchanged results remain cached. Also made physical identity explicitly
definition-local despite shared original source IDs, and fixed queue priority
to exact diameter plus stable cell key, excluding completion-discovered failure
reasons. World tolerance now enters jobs through root's derived local allowance.
Sent the exact revised wording to runtime/root for their independent review.

Root's integration review found two mapping normatives. Added explicit
Loop.traversal_adapter with original use order/sense retained and normalized
site/segment direction derived; source face orientation remains separate.
Added the pole role orientation formula -face.orientation*sJ, with
sJ=sign(delta_u*(g-v_pole)), and role-to-facet matching by physical identity.
Runtime now stores the loop adapter and mirrors the pole recipe. This prevents
reversing the bounded interpolant or blindly flipping all pole sheets alike.

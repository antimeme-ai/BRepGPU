# Interchange caller and reference experiment subplan

Design and plan accepted by the source, runtime and oracle reviewers. Root owns
one file-to-consumed-first-jet command, independent reference acquisition/query
utility, and a fresh-process complete-cost driver. Parser, source conversion and
source/native oracle have separate bounded owners with direct fleet red/green.

The caller uses unchanged ABI1 core/plugin, records every face outcome, uses a
normalized dyadic grid and native source/world conversion, and checks actual
request binding before independent qualification. Complete operation timers retain
required validation/status handling/cleanup; output writing and independent truth
work are separate. Original source bytes, original arrays, actual controls/jets,
source query identities and exact-affine versus submitted reference coordinates
remain inspectable. Reference utility uses the existing isolated usd-brep wheel,
exports only a copied sheet and queries imported source through actual scalar APIs.
No borrowed pointer or new dependency enters owned machinery.

After source review, run callers and reference comparisons on the fleet; follow
with one excluded warmup/three fresh-process measured repetitions per placement.
Do not use a scalar-reference/batched-owned speedup claim. Direct saved output
review is the check for this reversible command, avoiding a mirror test suite.

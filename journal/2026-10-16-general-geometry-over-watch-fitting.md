# General geometry before watch-specific tuning

The operator explicitly requested avoiding overfitting to the watch geometry.
Read the current native engine/binding, design/performance contract, authored
benchmark families and next Lawson proposal. Static source inspection found no
watch IDs, part names, dimensions or8300-node special case in the production
engine/binding. The strict-convex specialization tests actual general simplicity
and exact positive turns; source tokens only preserve caller identity. Existing
performance rows already include independent strip, convex, dense-concave and
hole families and selected original NVIDIA/Manifold domains. The unfavorable
strip behavior remains published. These observations do not establish universal
geometry coverage.

Added the operator's standing requirement to AGENTS and the native design.
Strengthened the proposed Lawson evaluation to choose independent initial meshes
and reference domains before tuning, preserve arbitrary IDs/exact metrics and
report separate per-family cost/work/memory including regressions. The watch is
a retained real workload; its transforms alone cannot establish generality.
Specializations need checked geometric preconditions. Model-specific dispatch,
tolerances, capacities and sample-count assumptions are excluded.

Documentation/instruction changes only; no production source or geometry
contract changed, and no extra test/benchmark campaign was started. Reviewed
the edits against the current code and ran diff checks. The first native unit's
published outcomes and the whole main-plate timeout remain unchanged.

# Independent adjacency oracle unit subplan

Root recorded the direct fleet red: existing BodySampler healthy, then missing
`brepgpu.adjacency`, one test in0.063s. Root authorized the complete independent
Python oracle/direct-test unit after that red and accepted design/plan.

Build `adjacency_oracles.py` around two distinct contracts: literal signed
canonical source projection including original loop/UV occurrences; and a
generic dictionary/list relation model over submitted source keys and raw input
arrays. Decode downloaded output bytes independently with struct, compare full
row multiplicities and actual per-edge/per-use reader outputs. Product CSR,
result readers and native construction helpers never supply expected truth.

Extend direct fleet-only tests with box/cylinder/plate role truth, repeated mixed
instances, independent storage permutations, all incidence classes, empty
inputs, deterministic random graphs, crowded edges and a65,537-edge uneven
recursive-scan fixture. Test input rejection/immutability and result methods as
public interface behaviors. Native C admission/fault tests stay with the native
owner to avoid duplicate fault oracles. Root serializes actual fleet execution;
this lane writes files and performs static checks only. Root integrates code
review, measured qualification, mutation sites and publication.

# Actual Boolean-result mesh caller implementation

Implement the accepted design/plan as one actual-consumer unit. Retain actual
CutResult/CutSolid/history identity and use existing mesh leaf records. Extract
only common mesh-data export from canonical source export, and add explicit SVG
shape/namespace labels while preserving existing canonical byte output defaults.
New mesh_cut caller exports named original operands, actual result graph/carrier
control bits, sections, arrangements, selections, full history and shared indexed
mesh data. Its useful wall directly encloses fresh mesh plus every indexed/source
record and typed forward/reverse history lookup to actual original entities.

Four serial cases follow the reviewed plan. First output is independently
qualified outside useful wall; later immutable output and actual indexed/history
buffers correspond directly. Operand creation, Boolean construction, independent
qualification, correspondence and writes are explicit separate costs. Source pins
cover all directly used owned construction/oracle/export files before/after runs.
No dependency, canonical guard widening, fake shape/packed CutSolid, native/GPU
mesher, or device transfer. Product execution waits for parent fleet-green.

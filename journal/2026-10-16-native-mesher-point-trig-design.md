# Canonical point trig proposal

Prepared `docs/native-mesher-point-trig-filter.md` before implementation. The
proposed fixed dyadic/table-assisted filter is confined to canonical points;
explicit jets/metrics retain the existing arithmetic policy. It has independent
enclosure/vector and same-point cost checks, with old exact-Rational fallback.
No code, table generation, native execution, or performance claim in this step.
The persistent numerical service is the immediate integration priority.

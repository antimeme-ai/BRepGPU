# OM10 assembly, explosion and complete caller subplan

Purpose: retain the whole imported movement as reusable definitions and distinct
root-to-leaf occurrences, then consume its real native CPU/P100 output in readable
assembled and exploded graphics. Geometry/meshing and native display are separate
owners; this unit does not reconstruct or cosmetically substitute geometry.

Read source inventory, import/native/oracle studies, reviewed integrated design
and plan, prior watch caller and its export/timing behavior. Child-local to parent
maps compose by column-vector application: parent.rotation*child.rotation,
parent.rotation*child.translation+parent.translation. Independent expected raw
STEP source placement is supplied by oracle lane, not a second product cache.

1. Independent owner writes literal nested noncommuting placement fixture and
   missing imported_assembly API red on fleet. Root then implements immutable
   Occurrence(id,path,product_id,definition_id,name,reference,transform) and
   Assembly(root_product_id,occurrences,groups). Definition IDs cannot identify
   repeated parts; complete usage paths can. Sort child usages by source ID for
   documented stable DFS ordering. Validate graph/reference uniqueness, active
   path cycles, rigid finite maps and exact actual root leaf inventory.
2. Keep source names and references. Derive Group records from nonleaf paths;
   no false label inferred solely from a colored silhouette. Explosion stores
   world offsets per occurrence; explicit group and leaf layout parameters can
   produce staggered lifts and detail isolation. Rigid transforms keep rotation;
   at alpha0 return original tuple values before offset arithmetic. Validate
   alpha, offset completeness/finite arithmetic and original immutable inputs.
3. Build native scene instances over mesh.write_scene and exact BGVIEW01 requests.
   Match camera, quality, palette, lights and alpha across backends. Use actual
   per-definition physical mesh bounds for framing. First evaluate/project-only
   requests qualify all CPU/P100 geometry/assembly before rendering the watch.
4. Caller writes complete BOM/path/transform/layout and per-source-face mapping
   TSVs, source/software/view/quality pins, actual native stage rows and directly
   timed external walls. Encode raw native RGBA as PNG with standard-library
   zlib; compose labeled SVG using actual mapped ID/depth anchors, grouped hero
   labels and full detail/BOM plates. Final static SVG-to-PNG composition uses
   existing tool separately, explicitly timed. Original CAD header remains private.
5. Green direct assembly cases and native caller fixture; adversarial oracle
   review resolves real findings. Integrate full original source and independent
   complete geometry/placement checks. Only after all capability/source greens
   and reviews: actual whole assembled/exploded images, saved ID/depth/BOM/image
   inspection, focused fixes and quiet matched repeated cold/reused benchmarks.
6. Publish honest CPU1/multicore/P100 stage/full costs in graphics and readable
   report with original source attribution. No full functional watch/GPU solid
   construction claim. Meaningful commits/merge preserve branch history; stop
   after complete deliverable, no alpha or new certification lane.

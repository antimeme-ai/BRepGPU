OM10's2021 funding dossier is historical: it requested prototype financing;
current physical-prototype evidence and actual download access need separate checks.

Current extrusion code admits XY coordinates only on1/256 grid in±3/4 and
height≥1/4. Uniform Frame scaling cannot change aspect ratio: thickness / any
axis span is at least1/6. Thus many thin real movement parts need a researched
new dimensional contract before an accurate reconstruction, even if a high-res
outline is available. This is a source review, not a newly run geometry test.
Do not silently stretch thickness, infer unknown dimensions from pixels, assume
involute teeth, or treat a source CAD model as an independent manufactured-part
oracle. No product code, build, benchmark or test is run by this study.

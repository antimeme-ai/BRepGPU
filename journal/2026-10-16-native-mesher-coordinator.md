# Whole native coordinator

The accepted whole runtime now connects the existing native owners, without a
second mesher or Python geometry/scheduling. Source preparation retains original
bytes, compiles original rational roots, constructs complete source envelopes,
transports quality through actual assembly placements, and freezes definition
envelopes plus the shared immutable numerical root bank. Its private arithmetic
dies before publication; subsequent jobs import only sealed values.

Per-definition coordination owns the shared boundary forest and physical-node/
facet registry. Face preparation and refinement yield numerical/candidate child
requests. Every current face reaches its canonical boundary request/settled
horizon before shared splits. Complete settled faces enter the same contact
epoch; both-side marks resume the affected face owners. The stable global
optimizer approves bounds and current contacts before each ordered commit.
Only the complete semantic NativeMesh and required display outputs publish.

Scheduler scratch, persistent owner work and numerical runtime work are separate
counters. Resource admission is bounded; a worker never waits for queued work.
Cancellation stops admission, drains tasks/device sessions, then destroys owners.
Native complete operations, independent families and the supplied complete watch
remain the final integration/performance targets.

The actual source→shared-curve points→persistent preparation owner→reused
numerical service→same face owner chain passes CPU1/4. Tight curve chords
request a shared interval; loose authored geometry reaches two accepted cells.
The candidate child uses the independently specified polynomial point and
physical diametral-feature result. The test initially expected that point to be
unprotected; its exact dot product is -11/64, so the oracle now requires the
source-edge request. The production predicate was correct.

Preparation and refinement use the submitting scheduler's cancellation token,
separate persistent arenas and sealed transfers. The refinement owner emits
immutable physical contact deltas, optimizer edge/proposal/commit replies and
the final FaceResult on its worker. The coordinator never evaluates a mutable
face Budget. Focused source/face jobs pass strict and ASan/UBSan/leak checks.
Actual-source review found foreign RunResource admission in FaceOwnerJob;
boundary, geometry and metric leases must now share the submitting run.

Whole-definition coordination is being connected in meshing_run.cpp. Source
splits occur only after every current face arrives. Contact deltas retain
unaffected facets, reuse retired slots only after the complete fold, and mark
both current offending cells. A stable source-face/site-edge queue reserves
each optimizer transaction through numerical acceptance, contact approval,
face commit and physical-scene replacement. Physical node lookup uses packed
rows with an owned Robin Hood index; face facets use generation-checked dense
slots, avoiding one tree allocation per node or triangle. Output ordering comes
from source keys at publication, independently of these lookup buckets.

The connected whole-operation fixture reached a genuine missing-coordinator
link failure before the implementation target was registered. It checks the
nonlinear planar two-triangle case and a curved polynomial family, all-source
inventories, shared boundary/refinement horizons, actual publication/readback,
independent original-polynomial samples, and CPU1/4/P100 semantic byte equality.
Its implementation checks are in progress; no complete watch is claimed.

The actual semantic-mesh producer now feeds SceneStore and its explicit source
profile file into the existing native CPU consumer, including real source-jet
evaluation. Direct occurrence material probes pass CPU and both P100s. Peer review
found the constructor/file-decoder finite validation asymmetry and a matching

validation before the executable publishes required graphics. This is one
boundary contract, not another geometric certifier.

   ordering/word predicate; preserve signed-zero/subnormal comparisons.

   index/page/info/download calls; same-context lock, checked pages and cleanup.
3. CUDA resident index/page tokens and actual-storage downloads through existing
   guarded/Pending/device/stream machinery, pure same-v1-base factory.
4. Lazy Python ABI declarations, bounded records, guarded resource publication
   and owned downloads; send canonical interfaces to the oracle/scene owners.
5. Extend the existing modeled callback/fault suite and CMake scenarios for
   new lifetime/alias/capability/poison/publication/copy/restoration paths.

   reviewers attack the completed unit, owner integrates every valid finding.

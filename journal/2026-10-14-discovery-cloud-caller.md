Parent assigned the complete caller/SVG unit after the iteration3 design and
plan were reviewed and implemented. Added examples/discover_cloud.py and
docs/DISCOVERY_CLOUD.md. This consumes the existing public hierarchy/discovery
API without a UV seed or solver replica. Default1024 targets are unique dyadic
normal/radial queries with exact analytic global distances. One synthetic
untrimmed local patch is named; no imported body/face or trim claim is made.

The caller downloads and exactly qualifies every cache node, then checks each
original-input UV witness and analytic global bracket using the existing
Fraction helpers. Added one keyword-only option to qualify_row:
check_flat_lower=True remains the original standalone/corpus behavior;
False omits only the expensive method-specific all-leaf lower reduction and
requires an analytic global distance. It retains exact witness/global/gap,
descriptive-grade, flags and counter checks. No existing fixture, cache oracle
or default qualification calculation changed. Parent accepted this additive
consumer option and will rerun the current standalone source on the fleet.

Exports preserve target/control/result bits, source IDs, exact witness/global
ratios, actual downloaded cells/caches and work populations. The owned SVG
retains unresolved rows and labels cached boxes as cache geometry rather than
a query trace. Timings expose hierarchy/cache inspection, qualification and
Python export costs separately from resident discovery. All resources are
closed even after failure; primary exceptions survive cleanup failures.

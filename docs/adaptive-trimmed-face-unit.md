## Purpose and actual operation

Consume the original SourceStore definition, one named original face, complete
shared physical edge/use snapshot and regular-purpose surface cache. Emit a
COMPLETE selected trimmed-face mesh: original loop intervals, holes and seam
occurrences, regular interior packets, connected band facets, source-keyed sites
and actual whole-facet error bounds. A set of clipped leaf fragments, one CDT
component, point evaluator or bound-only demo does not complete the operation.
A selected face artifact is not a completed component/assembly NativeMesh.

Native CPU and P100 consume the same original source and numerical profile.
Reuse existing source compilation and resident execution rather than eager
GeometryStore/FaceEngine. Exact topology and unresolved finite arithmetic stay
native CPU work. GPU must actually evaluate/restrict/bound the selected surface
and actual facet tasks. No production Python callback. No new dependencies.

## Finite source/domain dispatch

Reconstructed guides retain their original facts and source-node guards; the
chosen PL domain is explicitly the selected reference domain. Authoritative
identity requires a retained producer-checked whole-use image profile: original
2D source curve/map/lift, exact segment endpoints/line/scalar order, exact chosen
chain image and original loop joints. Small parameter chord error or a zero
boundary upper is not that profile. Unknown curved-authoritative interior maps,
physical-plane inverse charts and singular quotient cells return named
unsupported until their real producers/consumers exist. They remain required
future dependencies before promised full imported/assembly support.

Original physical XYZ/keys and current constructed revisions come only from the
shared physical authority. Opposite uses and same-face seams retain separate
chart occurrences while referencing the SAME physical values. No leaf/trim
intersection becomes a private physical source-edge sample. Source node delta
is separate from actual positional error; original coordinates already use mm.

## Selected construction and numerical invariants

Admit complete chosen loops with exact predicates/closed contact rules. A packed
segment index classifies accepted surface leaves; a tiny hole contained in a
leaf must be seen even when all four corners look inside. Wholly interior leaves
produce common-schedule positive packets. Pinch demotion remains monotone and
creates band material rather than deleting a source feature.

Combine normalized original loops with REVERSED packet rims. The direct-CDT
constraint recovery and right-side void flood can select all band components/
holes without another containment hierarchy. The typed extension must admit
strict interior anchors, count protected boundary vertices B separately, and
check T=2N-B+2H-2C for C positive components/H negative holes. Preserve the old
single-outer entry point and original source traversal adapters. Predicate
coordinates use exact common-denominator clearing with one D for BOTH axes;
retain original coordinates and chosen metric in output.

Each emitted triangle has one actual affine L from its three stored XYZ values.
Indexed leaf candidates and exact virtual clipping cover it completely, carrying
ORIGINAL-triangle barycentrics so every piece uses SAME L. The cached source
bound e plus whole-piece B-L bound is a valid route; stronger direct original
rational/analytic bounds may avoid unnecessary construction changes. Domain
transport, when admitted, is paid once through an actual map lease. Original
C0 spans partition source bounds; no C2 assumption crosses them.

A complete failure horizon first tightens SAME-L bounds within the finite policy.
A failed BAND triangle installs a new exact strict-interior anchor and refines
the implicated cache leaves before rebuilding its affected region once. A failed
PACKET triangle instead selects a prepared-root-relative dyadic target strictly
inside it and refines the same cache until that target is an ACTIVE common-grid
corner consumed by the packet builder. An existing retained numerical sample is
valid; the construction site must become newly active. Splitting one leaf alone
does not suffice: a skinny zipper triangle can survive that split unchanged.
Active strict-interior incidence prevents that old triangle from surviving a
conforming packet rebuild. Packet bound failure does not demote its footprint.
The entire unique target/path horizon is reserved before mutation. No target or
activation path within the axis-depth64 cap is typed unresolved. BAND anchors
retain arbitrary-word exact coordinates under their separate arithmetic cap.
Exact overlap centroids and dyadic interior search provide finite locators;
neither path assumes binary64 interior representability.
At a closed split-line tie the target follows one canonical containing child;
retained companions and common atomic side events propagate hanging incidence.
Activating a target does not require balancing every touching leaf.
Numerical floors request authority promotion, source/domain failures request their
real authority, and budget/depth exhaustion stays unresolved. No termination or
triangle-quality theorem is inferred merely from this progress rule.

First identity/selected-domain profile also admits boundary QUALITY explicitly:
each chosen protected trace-to-actual-chord upper must fit the exact requested
face tolerance, and each source-node upper its requested separate cap. A coarser
boundary cannot silently serve a stricter face query. Cache/B-corner promotions
remain under the cache owner. A proved unchanged physical-boundary point floor
returns named source/precision unresolved; it never triggers futile edge splits
or a private Q replacement. The existing boundary operation already settles its
own point precision at that same quality. Explicit cross-authority physical-point
promotion demands for future nonidentity domain budgets remain later machinery.

selected-domain-minus-packet chain equality, positive exact triangle areas,

source aliases/seams and exact original inventory. Original Fraction POWER/
rational and analytic models supply whole-facet error checks independently of
production restricted nets. Backend equality is separate placement evidence.

nonlinear line-image source boundary, authoritative identity and missing-map
refusal. Malformed/stale/partial/cancelled/exhausted inputs must not publish.

Record complete cold process and prepared fresh constructions, surface/boundary/
classification/packets/CDT/actual-bounds/anchor horizons/output/close, work counts,

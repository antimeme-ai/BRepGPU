# NCSX as the continuing trophy target

Operator direction, 2026-10-15: use the abandoned PPPL stellarator as our trophy
rendering subject, providing comparable progress between iterations. Acquired
the existing reference pack:13 files,18,360,279 bytes. Original files and an
intact acquisition archive remain in ignored quarantine; the public
[file inventory](../papers/ncsx-material-inventory.tsv) records SHA256 and sizes.
All eleven supplied manifest entries match. No new external package was adopted.

The subject is NCSX, the National Compact Stellarator Experiment. The pack contains
engineering PDFs, page images and an assembly photograph; it contains no native
CAD model, surface control nets, triangle mesh or machine-readable coil curves.
Documentary renders must not be represented as BRepGPU geometry output.

## First source-based rendering

After inspecting this documentary pack, acquired separate scientific Fourier
coil centerlines and an NCSX plasma boundary with their original MIT license.
[Study00 and the goal-object roadmap](NCSX_GOAL_OBJECT.md) now provide an actual
P100-evaluated rendering and recorded comparison baseline. These inputs do not
supply the engineering vacuum vessel, winding forms, ports or supports; plasma
must remain separately labeled.

## Read first

- [PPPL-4742, 2012 project review](https://bp-pub.pppl.gov/pub_report/2012/PPPL-4742.pdf):
  PDFpage4 shows the labeled complete-core concept and vacuum vessel; page5
  includes a vessel-sector photograph and eighteen-coil assembly rendering.
- [Modular-coil manufacturing](https://ncsx.pppl.gov/Closeout/Chrzano_Mod_Coil.pdf):
  page2 presents the three modular-coil forms, page4 the winding-pack section,
  page8 the handling/winding fixture. The source pack also contains a separate
  manufacturing photo album.
- [Vacuum-vessel preliminary design](https://ncsx.pppl.gov/Project_Control/PDR_PC/restricted/SSD_WBS_11_12_final.pdf):
  PDFpage12 contains the dimensioned vessel drawing; page13 the port map.
  This is preliminary design material, not an assumed final/as-built revision.
- [PPPL-4114, vessel fabrication](https://bp-pub.pppl.gov/pub_report/2006/PPPL-4114.pdf):
  CAD and manufacturing photographs on PDFpages3–6.
- [Closeout analysis slides](https://ncsx.pppl.gov/Closeout/AnalysisOverview_Heitz.pdf)
  and [half-period assembly photograph](https://ncsx.pppl.gov/NCSX_Engineering/FieldPeriodAssy/MCHP_Assembly/IMG_0887.JPG)
  provide additional engineering and construction references.

## Comparable iterations

The first actual NCSX scene uses the pinned scientific coil/plasma data recorded
in study00. Future engineering geometry and any reconstruction from drawings
must record its revision, assumptions and measured limitations. Retain the
same source geometry, units, view/crop, resolution, lighting and component
visibility between comparison images. When one changes, name it rather than
crediting its visual difference to a kernel improvement.

Separate source acquisition/reconstruction, supported carrier evaluation,
trimmed-face meshing and assembled topology. Show which actual BRepGPU operations
produced each image and their unresolved/unsupported portions. The existing
synthetic trophies remain historical demonstrations; NCSX is the continuing
visual target. Canonical meshing has its own completed bounded beachhead;
the full NCSX model requires substantially broader input geometry and operations.

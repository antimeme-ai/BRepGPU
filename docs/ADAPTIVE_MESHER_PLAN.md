## Selected first-checkpoint interfaces and procedures

The normative numerical, cache and construction procedures are the selected
sections of [the geometry report](../papers/native-adaptive-subdivision-geometry.md),
[runtime report](../papers/native-adaptive-subdivision-runtime.md), and
[algorithm report](../papers/native-adaptive-subdivision-algorithm.md), integrated
in ADAPTIVE_MESHER_DESIGN.md. They close the prior menus as follows.

`SourceCache` takes an immutable SourceStore lease directly. `PatchQuery` names
that lease, explicit original carrier/chart rectangles, query generation,
definition allowance, arithmetic profile and resource/depth limits. A session
owns reusable roots/nodes/samples. Nonblocking steps return progress, pending
common fallback, complete PatchMesh or typed error. PatchMesh contains actual
XYZ, original exact parameters, positive conforming triangles and root/leaf
associations. A patch request is not a complete B-rep inventory or a completed
component. No old eager GeometryStore/PreparedRun is constructed merely to
obtain an API handle.

The geometry owner supplies the shared finite packed geometry types and one
host/device numerical kernel, including original-coefficient interval Cox/Bernstein
root extraction, original analytic descriptors, actual point construction,
source-to-bilinear bounds, degree2 actual-facet residual and directional scores.
CPU preparation validates/indexes source and compiles requested roots once;
it does not restrict all eventual leaves before upload. Exact root extraction
and original analytic evaluation are bounded common fallback tasks. The ordinary
point profile is rn64_anchor32_p128_v1; fixed128/192/256 and exact are escalation
tiers. Promotion is a point-authority generation transaction, never a face-private
choice. Numeric-floor ambiguity does not create repeated geometric splits.

The runtime owner supplies packed SoA nodes/slabs, canonical frontier scans,
CPU/P100 source restriction/point/bound execution, counted-before-mutation
capacity checks and barrier reclamation/replay. Cache identity includes original
root and full split path; request identity also includes source/cache/query/
profile generations and ordinal. Selected leaves are a separate query mask.
Use cheap cached directional upper scores, fixed U ties and longest-active-axis
fairness every fourth failing split. Only exact affine-separable approximation
dependence (pure second AND mixed derivatives zero) disables an axis, allowing
linear translation. No exact transcendental work is justified solely by a
heuristic axis tie.

The construction owner supplies canonical side endpoint schedules and the
no-center positive zipper triangulator. The first patch output must use these
real common schedules, including adjacent original spans and unbalanced depth;
independent leaf triangles with cracks do not complete the checkpoint. Exact
coordinate identity and canonical point ownership precede triangulation. Shared
knot ownership requires original C0 continuity; unsupported discontinuities are
reported rather than treated as XYZ welds or invented metadata branches.

Root wires the strict native targets and a complete source-to-patch caller with
an explicit patch-only operation name/scope, CPU threads or selected P100,
declared resource limits, actual triangle output and cold/prepared/warm stage
costs. Independent original-source formulas check emitted facet interiors.
CPU/P100 full output equality checks deterministic placement separately. Tests
exercise actual GPU geometry/frontier work and meaningful sample/control reuse.
No new display stage is required merely to prove that triangle output exists.

# Finite pole/source-quotient publication

Extend the existing publisher, wire format and SceneStore consumer; retain every
original source occurrence independently of construction topology. This unit
copies the settled geometry/topology producer's finite cap descriptors and
canonical bounds. It does not recalculate geometry or add a coverage checker.

1. Build explicit source-site→published-site rows from FaceResult.source_sites.
   Validate every present mapping against the seed's exact chart/original UV,
   stored physical key/XYZ and retained recovery enclosure. Active result sites
   keep their actual ordered table and actual topology lineage. For each absent
   source site, append a semantic-only MeshSite and one initial source lineage
   with that site as its parent_site and no parent lineage. No triangle/cell or
   fictitious T0 triangle is added. Initial LINEAGE already admits a list of
   source sites rather than requiring a triangle. Normalized original loops,
   use samples and B/T source supports resolve through this full mapping; live
   triangles resolve through the actual active table. No seed-prefix inference.

2. Preserve complete settled master chains and both declared-collapsed endpoint
   occurrences even if their exact spatial t/key values coincide. Use traversal
   order chooses the expected master row directly, then checks parameter/key,
   rather than searching an ambiguous repeated parameter. Read each original
   joint VertexID from the original edge endpoint/sense, never the representative
   physical key. Retain the quotient's separate literal mapped-pcurve endpoints
   in USESAM rows. A collapsed use has no fabricated positive curve profile;
   its complete original edge/use/source intervals and sampled recovery remain.

3. For each face, group actual declared-quotient physical keys AND every
   FrozenPoleCap.pole_site key, including unchanged same-ID original vertices,
   and create its
   face-local MeshQuotient. Retain all original VertexIDs of the declared alias
   component from SourceBoundary.vertex_aliases, all incident original uses,
   every active/inactive site for that physical node, and incident actual cells.
   A matching FrozenPoleCap selects SphereNorth/SphereSouth/ConeApex; a regular
   incident face uses NoPole/joint. The first quotient in canonical face order
   anchors declared-component NodeGenerator::QuotientGenerator and optional
   MeshNode.quotient. Same-ID poles retain OriginalVertexGenerator and their
   original key, with the optional quotient attachment. Other face-local
   quotient rows retain the same canonical node without welding other keys.
   Source MJoint and closure rows retain original endpoint IDs and the face-local
   quotient; quotient kind selects the closure pole/apex/joint tag.

4. Each triangle.pole_piece selects its actual FrozenPolePiece and cap. Resolve
   pole/left/right source roles through the explicit mapping, verify their
   physical keys match the actual triangle, and copy PoleFanMap with original
   cut_uv, symbolic pole tag, local angular endpoints, normalized xi/rho=[0,1],
   cut revision/face generation and ordered local two-site cut chain. A local
   chain avoids repeating an entire K-piece cap in each of K map rows. Store
   PoleBilinearFan interpolation and the real physical role→facet permutation by
   keys. Use the already-positive-chart triangle roles, then apply original face
   orientation exactly once. Copy position_upper and band_upper as separate
   canonical actual-cell and pole-band components; definition allowance remains
   an allowance. No rounded singular constant or manufactured UV root is stored.

5. Corner locators name the face-local quotient only when their physical node
   belongs to it. Cut corners remain regular. Existing SceneStore reads exact
   retained cut UV to establish regular sheet signs for the actual pole corner;
   no radius sign at rounded singular UV is substituted. Keep original stored
   XYZ in all CPU/P100 consumer channels.

Auth identity-cap input must carry its actual named identity DomainMap. General
nonidentity authoritative B/T+cap remains the geometry producer's explicit
unsupported branch. No publisher fallback changes that geometry scope.

Author a focused actual source→producer→FaceEngine→publisher→wire→SceneStore
fixture first and observe existing publisher RED. Use independent literal
north/south/cone pole XYZ and derivative-cross/source-face orientation answers,
original same/distinct VertexID components, collapsed t with noncollapsed
pcurve interval, missing source mapping and stale cap identity refusals. Exercise
actual CPU/both P100 v2 source consumers. Existing publisher ordinary/plane/
authoritative/mixed fixtures remain the affected compatibility set. Scoped
strict/sanitizer/static checks and peer review close the unit; no additional
certification or random geometry campaign.

# Boolean-result mesh delivery plan

Issue52. Implements the accepted CUT_MESH_DESIGN, connecting one actual Boolean
result family to useful meshes. Semantic, oracle and caller design reviews
accepted the contract. Feature meshing and the other tranche lanes remain separate.

1. Independent oracle owner writes cut_meshing_oracles.py and test_cut_meshing.py,
   with imports of the future API and actual owned difference inputs. Run genuine
   fleet red before production module exists. The source-first oracle may reuse
   elementary independent patch/chain/ring predicates, not canonical qualification
   or product mesher helpers. Check actual cutter frames/raw V band, precise
   source generators, whole exact/rounded positive chain domains, ring embedding,
   physical incidence/vertex links and bounds. Include direct actual-output faults
   for distinct geometry/map/type failures. No proxy passing counter or suite-wide
   mutation claim is needed. No new general test framework.
2. Parent owns complete product constructor and lazy CutResult adapter. Reuse
   immutable mesh leaf records and genuinely generic arithmetic only. A dedicated
   rounded guard checks actual CutSolid extrusion geometry without .shape or
   factory reconstruction. Original canonical meshing admission stays intact.
   Read actual result edges/coedge maps/loops, infer rings by face ownership and
   raw wall band from actual source records. Plane UV uses each actual patch Frame;
   wall UV keeps raw V and quadrant. Validate exact and rounded geometry, bounds
   and expected resource counts; publish only immutable complete output.
3. Sync changed files to the fleet and run direct green. Semantics colleague
   reviews actual code and oracle for source/coverage/embedding invariants. Oracle
   owner resolves valid independent-check issues. Record any false findings with
   reasons. Run affected compatibility once after final product changes using the
   existing protected core/plugin; no rebuild or overlapping performance worker.
4. Caller owner implements mesh_cut.py and benchmarks/cut_meshing/run.py after
   plan acceptance. Reuse indexed reader and compatible SVG/mesh-data export
   helpers while preserving canonical defaults and truthful captions. Dedicated
   cut source exporter retains exact original operand packed tables, actual result
   graph/controls/sections/arrangements/selections and all-kind forward/reverse
   history. Each useful repeated wall starts before meshing and ends after full
   indexed plus actual typed history lookup consumption. It must bind .cut_result,
   .body and .history to exact actual input objects. Pin sources before/after.
5. Run caller and the four-case serial matrix on fleet: unit1/2, unit1/1024,
   translated scale2 at1/4096, subnormal origin scale1/4 at1/4096. One first,
   one excluded warmup, five repeats. Independently qualify first output once;
   later full geometry/source/history identity and reader buffers correspond
   outside useful walls. Preparation/Boolean, qualification, correspondence and
   export costs stay separate. Directly wrap full mesh+indexed+history work;
   no sum of phase medians. These vary resolution/frame, not Boolean complexity.
   No device calls/transfers or GPU speedup claim. Retain all actual artifacts.
6. View the actual saved SVG/PNG and inspect source/UV/history tables. Colleagues
   review actual code, saved results and measured interpretation. Resolve all
   valid findings. Publish API/report, README graphic, research index, issues and
   return-pass/roadmap notes, distinguishing this completed connection from
   feature meshing and incomplete external alpha qualification. Preserve current
   reference issues43/48 and original NCSX baseline.
7. Commit/push coherent research, red, constructor, caller and result checkpoints.
   PR merge preserves commits and remote feature branch. Sync main to fleet,
   verify clean source worktrees and unchanged protected native hashes, record
   merge/handoff journal. No additional optimization/rewrite starts in this unit.

All geometry, tests, callers and injected faults execute on the fleet. Local
AST/source/link/hash checks and static asset conversion/viewing are permitted.
Independent known-answer geometry and whole-domain coverage justify the direct
suite; no redundant formal system, exhaustive GPU campaign or mutation score
is added for this CPU-only connection.

## Direct TSV interface

Reference owner accepted `reference-outcomes.tsv` with exactly two configurations,
heal0 andheal1, in fixed display order, regardless of success. Required columns:

| Column | Contract |
| --- | --- |
|config|heal0 orheal1; unique|
|view|both|
|scope|fresh_step_both_labeled_views for completed admitted success; failed_pipeline,failed_qualification orunsupported for failures|
|n|1 actual complete observation or failed attempt; no inferred/repeated total|
|status|PASS,FAIL orUNSUPPORTED|
|complete_seconds|finite nonnegative actual complete fresh source→both PNG/labeled-SVG→exit wall; required forPASS, otherwise blank unless an actual completed diagnostic render failed admission|
|elapsed_seconds|finite nonnegative actual attempt wall, at least complete_seconds when present; no invented elapsed value|
|source_sha256|actual original source SHA-256; must match owned full caller|
|views_sha256|SHA-256 of actual requested two-view BGVIEW01; must match owned full caller|
|detail|actual outcome/stage explanation, retained in the published TSV|

PASS additionally means independent geometry admission is green. The producer
owns these factual claims; this compositor only checks the direct typed input,
identity/scope consistency and formats it. It does not certify the reference
kernel or invent timing from worker stages. The owner will write the two actual
outcomes from the actual external calls; no favorable-healing selection.

The final compositor requires an explicit `--reference-outcomes` input. Missing,
duplicate or unknown configuration/status, nonfinite/negative/missing required
timing, mismatched source/view or a per-pose scope fails composition before
writing final posters. Retain the input table beside the existing actual timing
and pin tables. Published values must come from measured actual rows.

PASS rows show the real complete seconds. Failed/unsupported rows show explicit
status and no comparable completed total, even when a failed-qualification row
retains a genuine diagnostic complete time. Their actual elapsed/diagnostic
times remain available in the outcome TSV/report. No speedup is calculated.
The panel/header/legend identifies NVIDIA CPU kernel preparation plus shared
owned CPU display, and distinguishes failed admission from completed full
workflows. Individual per-pose full walls are never inferred.

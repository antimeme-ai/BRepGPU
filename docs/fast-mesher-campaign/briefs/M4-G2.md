# M4-G2 brief: Face-to-edge feedback and its termination

Read with `M4-common.md`. Stub: `papers/2026-10-17-geometry-lifecycle-map.md` §4.1 G2. Bead: `brepgpu-12s.3`.

**Purpose.** The draft design freezes each shared edge chain once it is
sampled. Gmsh, OCCT BRepMesh and Parasolid all let trouble in a face (an
unrecoverable boundary, a self-intersecting UV wire, refinement near inner
loops) re-split the shared edge and re-mesh every face on it, in bounded
rounds. Define our loop: trigger, invalidation, a stop rule derived from
geometry rather than a count, and the refusal record.

**Decision it blocks.** M5 §5.2–5.3 coordination: frozen chains plus refusal,
or a coupled edge/face queue with schedule generations. Also how it interacts
with staged resolution, caching and determinism.

**Operator decisions that bind this lane.** D-determinism (identical output
across thread counts on one backend, so feedback rounds must be order-
independent); D-partial-output (mesh the rest, marked incomplete);
D-provisional; M2's adopted point-solve and structural-first defaults.

**Questions.**
1. How each mature mesher feeds face failure back into shared edges: OCCT
   `BRepMesh_ModelHealer`, Gmsh `meshGFace.cpp`/`Generator.cpp` (the PENDING
   and retry paths), Netgen, Parasolid's incremental refinement semantics, and
   any others you find. Give the trigger set, the invalidation set and the
   round limit for each, at a pinned revision.
2. Termination. Is there a geometry-derived bound on rounds, for example a
   minimum segment length from ε and local feature size giving a packing
   argument? Cite the literature on coupled boundary refinement (Ruppert,
   Shewchuk, Cheng–Dey–Shewchuk and successors) and derive what the sources do
   not give.
3. Determinism under parallel scheduling: schedule generations, canonical
   ordering of re-splits, and what is recomputed.
4. Interaction with growth clusters (`papers/2026-10-17-parallel-growth-
   clusters.md`), the background healer and staged resolution.
5. The authored families that force each branch (inner loop near the outer
   boundary, a UV wire that self-intersects only after sampling, and so on),
   and the refusal record when the bound is reached.

**Measurement.** None. Literature and reference code only.

**Output slug.** `face-edge-feedback`: `papers/2026-10-17-face-edge-feedback.md` and its sources TSV.

**Done when.** A stated loop with trigger set, invalidation set, a geometry-
derived stop rule and a refusal record, plus the authored families that force
each branch. Every question has an evidence-backed answer or an explicit "the
literature does not say" with the measurement that would settle it.

**Return.** The loop in ten lines and the stop rule with its argument. Then the
common return items.

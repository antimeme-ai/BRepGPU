# M4-G7 brief: Determinism contract and cache keys without bit-identity

Read with `M4-common.md`. Stub: `papers/2026-10-17-geometry-lifecycle-map.md` §4.1 G7. Bead: `brepgpu-12s.8`.

**Purpose.** The operator dropped cross-backend bit-identity and chose
functional identity, with identical output across thread counts on one backend.
Work out what that means layer by layer, so that caching, early cutoff,
regression and incremental equivalence still work.

**Decision it blocks.** M5's determinism statement, the cache key, and the §10
metamorphic oracles. G12 waits on this paper.

**Operator decisions that bind this lane.** D-determinism (identical across
thread counts per backend; functionally identical across backends; one model
may mix backends); D-provisional.

**Questions.**
1. Which output layers must be bit-identical per backend (edge samples, face
   triangles, export bytes), and the cheapest mechanisms for thread-count
   invariance: canonical ordering, deterministic reductions, no floating-point
   atomics, and fixed task decomposition (Blelloch et al. 2012 and successors).
2. "Functionally identical" as an oracle: which tolerances, which topology
   equalities, and which comparisons can never fail and so must not be used.
3. Mixing backends in one model: the shared edge layer must have one producer
   per edge, or watertightness breaks. State the rule.
4. Cache keys and early cutoff (Mokhov et al. 2018): geometry digest, ε,
   backend, code version, and which inputs a key must include so that a stale
   reuse is impossible.
5. Optional measurement: how often CPU and P100 FP64 evaluations of the closed-
   form density rules (cylinder Δθ, sphere radius, B-spline second-difference
   bound, with and without FMA) fall on opposite sides of a sampling threshold
   on corpus faces. Do this only if a small probe answers it.

**Measurement.** Optional, as in question 5: a small CPU and P100 probe on the
fleet.

**Output slug.** `determinism-cache-keys`: `papers/2026-10-17-determinism-cache-keys.md` and its sources TSV.

**Done when.** A determinism class per output layer, the cache key definition,
and the oracle for each class. Every question has an evidence-backed answer or
an explicit "the literature does not say" with the measurement that would
settle it.

**Return.** The class per layer and the cache key. Then the common return
items.

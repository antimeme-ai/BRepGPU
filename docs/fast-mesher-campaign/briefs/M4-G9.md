# M4-G9 brief: Instancing key and per-occurrence semantics

Read with `M4-common.md`. Stub: `papers/2026-10-17-geometry-lifecycle-map.md` §4.1 G9. Bead: `brepgpu-12s.10`.

**Purpose.** Define the mesh key, ownership, winding and normal handling, and
per-occurrence attributes for every placement kind the operator admitted.

**Decision it blocks.** M5 §5.1 and §5.5, and the accounting rule that makes
timing comparisons with NVIDIA fair.

**Operator decisions that bind this lane.** D-placements: rigid and mirrored
placements share one mesh; uniform scale gets a mesh per scale with ε scaled to
match; non-uniform scale and shear are refused explicitly. D-determinism;
D-formats.

**Questions.**
1. The key: definition identity, effective ε, scale class, code version and
   anything else that makes reuse sound.
2. Mirrored placements: winding and normal flip at emit, per format (STL, 3MF
   items, glTF, where negative-determinant node transforms have defined
   semantics).
3. Uniform scale: ε/s per occurrence, and whether occurrences at nearby scales
   may share a mesh made at the tightest ε.
4. Per-occurrence attributes: colour, ids and materials, and where they live.
5. How the NVIDIA baseline counts and emits instances, read from its code and
   existing reference artifacts (no new NVIDIA runs), so that timings compare
   equal work.
6. The CAx-IF AP242 assembly-structure recommended practice, unread so far;
   acquire it if open.

**Measurement.** Reading existing reference artifacts only.

**Output slug.** `instancing-semantics`: `papers/2026-10-17-instancing-semantics.md` and its sources TSV.

**Done when.** A placement table with key, ownership and emit rules, and the
accounting rule for comparisons. Every question has an evidence-backed answer
or an explicit "the literature does not say" with the measurement that would
settle it.

**Return.** The table and the accounting rule. Then the common return items.

# Original shared-curve numerical service

The same independent original-source reader passes 81 actual output records on
CPU and each P100. It reads point enclosures, actual constructed/fixed points,
departures and whole-interval chord bounds, including paired child restrictions
and dynamic carrier/pcurve trace pieces. Exact original Cox evaluation and
Fraction polynomial interpolation are independent of production extraction;
Decimal formulas supply the analytic source/derivative oracle. Coverage includes
original degree32 Bezier, nonclamped B-spline natural domains, C0 knots, rational
weights, line, circle/ellipse with nonorthogonal frames, reversed pcurve ranges
and virtual SAME-L restrictions across original carrier spans.

Strict Clang18 and ASan/UBSan/leak runs use the direct native fixture. It also
checks fixed negative-zero words, precise equality, original natural-boundary
hulls, nonfinite request rejection and exact-t enclosure ambiguity admission.
Scoped numerical/source reviews accepted the actual implementations after
findings were fixed. Tidy uses the named repository profile, with no added
suppression. This unit is the numerical service consumed by the shared boundary
and occurrence trace owners; it does not claim a complete trimmed-face mesher or
whole assembly mesh.

A real degree32 shared-boundary caller initially failed its original node cap:
reported upper 2.13261574029026215e-7 versus requested 1e-8. Curve-only convex de
Casteljau interpolation fixes interval dependency growth while retaining the
same original source and tolerance. The degree32 direct reader checks unforced
point departures below 1e-10 as well as original-source enclosure correctness.
Original Bezier nets are consumed directly; they need no Cox extraction.

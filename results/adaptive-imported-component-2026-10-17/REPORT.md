# First imported analytic component

The native cached-adaptive caller completed one original watch definition on
CPU4 and P1000 at the existing global positional/node settings, 0.005/0.001 mm.
This is four faces (three planes and one cylinder), not the whole watch.
The unchanged full original source was decoded and used for assembly allowances;
only the selected definition's carrier bank was compiled. Selection was an
explicit experiment scope, not production dispatch by source identity.

The independent reader checks original V/Ce/S node guards, whole original
surface-to-actual-facet bounds, complete face/use inventory, captured incident
chains and directed physical frontier. Both outputs pass, each with 32 facets
and no forbidden final contacts. All five paired curve/face artifacts are
byte-identical. Reader work is external to the native timings below.

CPU wins this small cold operation. These are overlapping stage accounts, not
rows to sum independently. Peak aggregate reserved memory was about 643 MB in
both processes. P100 performed actual curve and surface geometry work: the curve
owner uploaded/downloaded 51,120/12,096 bytes; surface owners uploaded/downloaded
30,456/4,800 bytes. Transfers mean host memory to/from device memory, excluding
SSH and source-file transport.

The reader's finite imported profile covers planes/cylinders and original
analytic line/circle/ellipse curves with the described source maps. It retains
exact original binary64 coefficients and arguments; it neither substitutes an
ideal frame nor declares sampling to be truth. Singular quotients, general
imported rational clocks and authoritative-domain maps remain separate work.
See [the reader plan](../../docs/adaptive-imported-analytic-reader-unit.md).

operation yet. This checkpoint establishes neither whole-watch completion nor
a GPU speedup. Saved original bytes, artifacts and raw operational logs remain

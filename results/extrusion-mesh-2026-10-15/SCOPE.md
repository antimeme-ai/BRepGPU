# Actual extrusion-result CPU mesh scopes

Each selected case prepares one original profile and ExtrusionResult, then produces one first mesh and three repeated fresh meshes. First output is excluded from medians. Complete wall wraps meshing, actual indexed buffers/record reading and typed original profile history traversal. First independent qualification and later full-output correspondence are outside that wall and named by phase. Profile preparation, original feature construction and first-output filesystem export are separate observations. Separate phase medians need not add. Imports, final summary/source writes and process shutdown are excluded. CPU-only, zero native/CUDA calls or device transfers; no speedup baseline or hardware claim. This is one bounded run, not a certification campaign.

# OM10 source-derived visualizations

Source design: **Association openmovement**, OM10 MAN VA01.3,
[OM10 project](https://openmovement.org/project/om10/).

The OM10 rendered images and SVG compositions in this directory are available
under [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/).
Retain source credit, this license link, and a description of changes when sharing
or adapting them. Source material and attribution research are recorded in
[the source note](../../papers/2026-10-15-om10-source-attribution.md).

BRepGPU supplies owned tessellation, the illustrative material palette,
camera/lighting, authored explosion offsets, labels and timing graphics.
The original movement design is credited to Association openmovement.
The software implementation retains the repository's separate software license.
Original CAD bytes and operational binary snapshots are not included here.

The `*-exploded-assembly-4k.png` diagrams additionally use authored functional
module translations, source-alignment guides and a complete166-name legend.
Original part orientations, geometry and materials are retained. These diagrams
are explanatory illustrations, not validated disassembly instructions. Their
[report](../../results/om10-exploded-2026-10-17/REPORT.md) separates new display/export
costs from the original completed mesh operation.

The `nvidia-heal*-exploded-assembly-4k.png` images use genuine NVIDIA CPU
reference tessellation of the same CAD, its supplied illustrative palette,
and BRepGPU CPU display, functional layout and labels. They retain the same
CC BY-SA3.0 source attribution. Their nominal tolerance request is explicitly
COMPLETE_UNQUALIFIED; no independently proved5µm or matched-quality claim follows.
